# 🤖 Telegram-бот расписания КФУ (Группа ИВТ-б-о-251)

Бот автоматически синхронизируется с официальным сайтом КФУ им. В.И. Вернадского (`cfuv.ru`), парсит актуальное расписание пар, учитывает чётность/нечётность недели, звонки (время начала и окончания пар), аудитории, корпуса, преподавателей и подгруппы.

### ✨ Главные фичи:
1. **Чистый чат (без спама)**: Бот держит в чате ровно **одно** актуальное интерактивное сообщение. При обновлении, вызове команд или утренней рассылке старое сообщение удаляется, а новое отправляется на его место.
2. **Интерактивные кнопки**:
   - `◀ Пред. день` / `📅 Сегодня` / `След. день ▶` — листайте расписание прямо в сообщении
   - `🗓 Вся неделя` — сводка пар на всю текущую неделю
   - `👥 Подгруппа` — фильтрация по подгруппам (Все / 1-я / 2-я)
   - `🔄 Обновить` — принудительный сброс кэша и получение свежих данных с сайта КФУ
   - `⚙️ Настройки` — выбор времени утренней рассылки (06:30, 07:00, 07:30, 08:00) или её отключение
3. **Автоматическая утренняя рассылка**: каждое утро бот удаляет вчерашнее сообщение и присылает свежее расписание на наступивший день.

## 🚀 Быстрый запуск локально

1. Склонируйте или откройте проект:
   ```bash
   cd RaspBot
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` (скопировав из `.env.example`) или `token.txt` и вставьте ваш токен бота:
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   GROUP_CODE=ИВТ-б-о-251
   ```

4. Запустите бота:
   ```bash
   python bot.py
   ```

## 🛠 Гайд: Создание бота в @BotFather

1. Откройте в Telegram официального бота: **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду: `/newbot`.
3. Введите **видимое имя бота** (например: `Расписание ИВТ-251`).
4. Введите **username (ссылку) бота**, оканчивающийся на `bot` (например: `ivt251_schedule_bot` или `cfuv_ivt251_bot`).
5. **Скопируйте полученный токен** (вида `7123456789:AAH...`) и вставьте в `.env` или `token.txt`.
6. *(Рекомендуется)* Настройте меню команд:
   - Отправьте `/setcommands`, выберите вашего бота и отправьте список:
     ```text
     start - Запустить бота и получить расписание
     today - Расписание на сегодня
     tomorrow - Расписание на завтра
     week - Расписание на всю неделю
     subgroup - Выбрать подгруппу (1, 2 или Все)
     settings - Настройки утренней рассылки
     help - Справка и возможности бота
     ```

## ☁️ Бесплатные хостинги без привязки банковской карты

### Вариант 1: Hugging Face Spaces (Рекомендуется ⭐⭐⭐⭐⭐)
* **Плюсы**: Бесплатный Docker-контейнер (2 vCPU, 16 ГБ RAM), работает 24/7, **никаких карт**, вход через обычный email/GitHub.
* **Инструкция**:
  1. Зарегистрируйтесь на [huggingface.co](https://huggingface.co).
  2. Нажмите **New Space** (Новый Space).
  3. Введите любое имя (например `cfuv-rasp-bot`), выберите **Space SDK: Docker** -> **Blank**, лицензия **Apache 2.0**, приватность **Public** или **Private**.
  4. Во вкладке **Files** загрузите файлы репозитория (`Dockerfile`, `requirements.txt`, `bot.py`, `config.py`, `database.py`, `schedule_service.py`, `keyboards.py`).
  5. Перейдите в **Settings** -> **Variables and secrets** -> **New secret**:
     - Key: `BOT_TOKEN`
     - Value: `<ваш токен бота>`
  6. Нажмите сохранить — Space автоматически соберётся и бот будет работать 24/7!

### Вариант 2: Serv00.com (Полноценный FreeBSD/Linux сервер ⭐⭐⭐⭐⭐)
* **Плюсы**: Полностью бесплатный хостинг навсегда, **без карты**, даёт настоящий SSH-доступ, cron и возможность запускать фоновые Python-скрипты.
* **Инструкция**:
  1. Зарегистрируйтесь на [serv00.com](https://www.serv00.com/) (письмо с логином и паролем SSH придёт на почту).
  2. В панели управления включите поддержку фоновых процессов: **Run your own applications** -> **Enabled**.
  3. Подключитесь по SSH: `ssh username@sX.serv00.com`.
  4. Загрузите файлы бота или склонируйте репозиторий.
  5. Установите зависимости: `pip3 install --user -r requirements.txt`.
  6. Создайте файл `token.txt` с токеном.
  7. Запустите бота в фоне:
     ```bash
     nohup python3 bot.py > bot.log 2>&1 &
     ```

### Вариант 3: Koyeb
* **Плюсы**: Современный PaaS хостинг, бесплатный Eco-тариф, **не требует карту** при регистрации через GitHub.
* **Инструкция**:
  1. Зарегистрируйтесь на [koyeb.com](https://www.koyeb.com/) через GitHub.
  2. Создайте новый сервис из вашего GitHub репозитория с ботом.
  3. В Environment Variables добавьте `BOT_TOKEN`.
  4. Сервис подхватит `Dockerfile` и запустится.

### Вариант 4: Старый Android-смартфон (Домашний сервер ⭐⭐⭐⭐)
* Если у вас есть любой старый телефон на Android, лежащий без дела:
  1. Установите приложение **Termux** (из F-Droid).
  2. Выполните:
     ```bash
     pkg update && pkg install python git
     git clone <ваш_репозиторий>
     cd RaspBot
     pip install -r requirements.txt
     python bot.py
     ```
  3. Оставьте телефон на зарядке с Wi-Fi — это ваш собственный бесплатный сервер 24/7!
